# The mock-up

The approved visual direction (`../DECISIONS.md`). Four screens, each a 1280×800
tablet frame, kept as design source: open a file to read its exact layout,
sizes, colours and copy. They were drawn as live artboards, render only in the
canvas that drew them, and do not ship with the program. The screens for a
next step with Split Rock, never built, and for a rail of stickies beside the
card, superseded by the dot in the title bar, are in Git history.

| Screen | What it shows | How it stands now |
| --- | --- | --- |
| `Capture.dc.html` | Capture over a card: Type and Pen, colour, Checklist and Remind, Belongs to, Done, saved as written | Replaced in layout by a card the size of the search (`../DECISIONS.md` § The quick note listens). What the card holds, the size of its controls and the note colours still follow it. Pen is not planned |
| `Board.dc.html` | The board and the planner: places down the side, today's timed notes, undated ideas | The places now run along the top (`../DECISIONS.md` § The board is a search); the planner on Today still follows it |
| `Search.dc.html` | Notes in Search, typed and handwritten | Built for typed notes; handwriting is not planned |
| `Spread.dc.html` | Notes on cards in Spread | Built, and drawn by Kadunce; a note placed on its window now stands in the same place on the card (`../DECISIONS.md` § In Spread, a note stands where it was placed) |

The screens are drawn inside Shuffle, in Shuffle's appearance. On its own,
Gooseberry follows the desktop's theme. The mock-up sets the layout, sizes,
touch targets, note colours and behaviour. Sample note text is illustrative.
