# Input

Every tap and key Gooseberry answers, and what you see happen. None is built
yet; this map is the plan, and it changes when the program does. How notes on a
card are shown and put away waits on `ROADMAP.md` § Open decisions, and is
added here once settled.

| Task | Touch | Keyboard |
| --- | --- | --- |
| Capture a note | Tap Gooseberry's button | None yet |
| Finish a note | Tap the work behind the sheet | None yet |
| Choose where it belongs | Tap a place under Belongs to | None yet |
| Write with a pen | Tap Pen | None yet |
| Set a reminder | Tap Remind | None yet |
| Open the board | Tap Gooseberry's button and hold | None yet |
| Tuck a note away | Tap Tuck away on the note | None yet |
| Bring a note back | Tap Tucked away on the board, then the note | None yet |

## Capture a note

| Input | What happens |
| --- | --- |
| Tap Gooseberry's button | The capture sheet rises from the bottom with the cursor in it. What you write is kept from its first letter. |

## Finish a note

| Input | What happens |
| --- | --- |
| Tap the work behind the sheet | The sheet goes down. The note is already kept; there is nothing to confirm. |
| Tap Done | The same. |

## Choose where it belongs

| Input | What happens |
| --- | --- |
| Tap a place under Belongs to | The note belongs there instead: the window in front, a project, the workspace, or Loose. |

## Write with a pen

| Input | What happens |
| --- | --- |
| Tap Pen | The page takes ink. A pen touching the page does the same. |
| Tap Type | The page takes typing again. |

## Set a reminder

| Input | What happens |
| --- | --- |
| Tap Remind | Choose a time, or next time this opens. The note goes on the planner. |

## Open the board

| Input | What happens |
| --- | --- |
| Tap Gooseberry's button and hold | The board opens on Today. |

## Tuck a note away

| Input | What happens |
| --- | --- |
| Tap Tuck away on the note | The note leaves view and waits under Tucked away on the board. |

## Bring a note back

| Input | What happens |
| --- | --- |
| Tap Tucked away on the board, then the note | The note goes back where it belonged. |
